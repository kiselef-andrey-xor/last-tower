# ПОСЛЕДНЯЯ БАШНЯ 🏰

Рогалик-оборона в одном HTML-файле: башня стоит в центре круглой арены и автоматически
отстреливается от волн врагов, наступающих со всех сторон. Между волнами открывается
**лавка**: случайный ассортимент улучшений, постройки и ремонт. Каждая 5-я волна — **босс**
(трофей = бесплатное улучшение). После гибели башни непотраченные монеты и награда за забег
уходят в **постоянные мета-улучшения**, которые работают во всех следующих забегах.

Технологии: чистый JavaScript + canvas 2D, процедурный звук на WebAudio, ноль внешних
ресурсов и зависимостей. Итог сборки — один файл `dist/index.html`, который можно открыть
даже с флешки.

---

## Быстрый старт

| ОС | Команда | Что делает |
|---|---|---|
| Windows | `start.bat` | собирает `dist/index.html` и открывает игру в браузере |
| Windows | `start.bat test` | headless-тест игрового цикла (52 проверки) |
| Windows | `start.bat balance` | симуляция баланса: 4 профиля игрока |
| Windows | `start.bat shots` | перегенерировать скриншоты (нужен Python 3 + Pillow) |
| Linux/macOS | `./start.sh` / `./start.sh test` | то же самое |

Вручную:

```bash
node build.js          # собрать dist/index.html
node tests/headless.js # прогнать тесты
xdg-open dist/index.html
```

Если Node.js не установлен, но `dist/index.html` уже собран — бат-файл просто откроет его.

Отладка экономики: откройте `dist/index.html?testgold=10000` — каждый забег будет
начинаться с тестовым банком монет (он не переносится в кошелёк после забега).
По умолчанию тестовый банк выключен.

## Управление

| Клавиша | Действие |
|---|---|
| ЛКМ по арене | поставить купленную постройку / выбрать точку орбитального удара / взять врага в фокус |
| ПКМ / ESC | отменить установку постройки или прицеливание |
| ПРОБЕЛ | режим прицеливания орбитального удара |
| Q / E / TAB | приоритет цели: ближний → крепкий → слабый |
| 1…5 | купить карточку в лавке |
| R | обновить ассортимент лавки |
| ENTER | начать волну досрочно (бонусные монеты за скорость) |
| P / ESC | пауза |

## Структура проекта

```
├── start.bat / start.sh   запуск: сборка + браузер / тесты / скриншоты
├── build.js               сборщик: template.html + style.css + src/*.js → dist/index.html
├── package.json           скрипты npm (build, test, balance, probe, seeds, shots)
├── template.html          HTML-оболочка с плейсхолдерами /*__CSS__*/ и /*__JS__*/
├── style.css              стили интерфейса (тёмный неон, адаптив)
├── src/
│   ├── core.js            утилиты, сохранение (localStorage + fallback), звук Sfx
│   ├── data.js            ВЕСЬ баланс: сложности, враги, боссы, волны, постройки, SHOP, META
│   ├── game.js            состояние забега, цикл, AI, снаряды, удар, ввод, resize
│   ├── render.js          отрисовка: арена, башня, враги, частицы, прицелы, фон меню
│   ├── ui.js              HUD, лавка забега, мета-магазин, экраны меню/паузы/результатов
│   └── boot.js            точка входа
├── tests/
│   ├── harness.js         фейковый DOM + загрузка бандла в vm, экспорт __api
│   ├── headless.js        авто-игрок: 40 волн, 52 проверки цикла/сейва/мета-прокачки
│   ├── balance.js         таблицы давления волн на 4 профилях («голый», умный, строитель, чит)
│   ├── probe.js           точечный зонд: состояние билда на волнах 12/20/28
│   ├── seeds.js           прогон headless по N сидам: медиана достигнутых волн
│   ├── snapshot.js        запись вызовов canvas в JSON-примитивы (shot-mid / shot-rich)
│   ├── rasterize.py       растеризация shot-*.json → PNG на Pillow
│   └── shot-*.json/png    свежие снимки кадров
├── android/               APK-обёртка WebView: манифест, исходники, иконка,
│   │                      build-apk.sh (сборка без Gradle), release.keystore
│   └── last-tower.apk     ГОТОВЫЙ APK (Android 5.0+, офлайн, без разрешений)
└── dist/index.html        ГОТОВАЯ ИГРА (результат сборки, лежит в репозитории)
```

## Тесты

`node tests/headless.js` — 52 проверки: старт забега, покупки, 40 волн авто-игроком,
боссы, делители, ограничение частиц, производительность кадра, смерть и рекорд,
чтение/запись сейва, мета-синергии, генератор волн, цены, спавн всех 11 типов врагов и 3 боссов.

`SEED=7 node tests/headless.js` — детерминированный прогон (mulberry32 вместо Math.random).
`node tests/seeds.js 8` — медиана/разброс по 8 сидам.

## Android (APK)

В `android/` — обёртка WebView без внешних зависимостей и готовый `last-tower.apk`
(Android 5.0+, полностью офлайн, ноль разрешений Android; портретная ориентация,
сейвы в localStorage приложения). Пересборка APK после правок игры:

```bash
node build.js                                  # свежий dist/index.html
cp dist/index.html android/assets/index.html
( cd android && ./build-apk.sh )               # JDK 17 + Android SDK (build-tools 34, platform 34)
```

Скрипт собирает без Gradle: aapt2 → javac → d8 → zipalign → apksigner.
Подпись: `android/release.keystore` (пароль хранилища и ключа `lasttower`) —
не теряйте ключ, обновления APK ставятся поверх только с той же подписью.
Если репозиторий публичный и ключ жалко показывать — уберите keystore из репо
и храните приватно (тогда после смены ключа старый APK обновится только переустановкой).
