# Android-обёртка «ПОСЛЕДНЯЯ БАШНЯ»

Офлайн-APK: вся игра — один файл `assets/index.html` (canvas 2D + WebAudio,
без сети и без единого разрешения Android). WebView отдаёт игру через
`shouldInterceptRequest` с виртуального origin `https://lasttower.local/` —
только системные API, **ноль внешних библиотек**, поэтому сейвы (localStorage)
работают и переживают перезапуск приложения.

> Урок v1.0: обёртка на `androidx.webkit.WebViewAssetLoader` падала на устройстве
> с NoClassDefFoundError — библиотека тянет рантайм-зависимости androidx.core,
> которые не попали в dex. Не добавляйте внешние библиотеки без полной упаковки
> их зависимостей; ручной `shouldInterceptRequest` здесь проще и надёжнее.

## Готовая сборка
`build/last-tower.apk` — подписан, Android 5.0+ (minSdk 21), targetSdk 34.
Установка на телефон: скопировать файл, открыть, разрешить «установку из
неизвестных источников». Интернет не нужен.

## Пересборка после обновления игры
```bash
# 1. обновить ассет свежей сборкой веб-игры:
node build.js                          # в корне веб-репозитория
cp dist/index.html <эта папка>/assets/index.html
# 2. собрать APK:
./build-apk.sh                         # нужны JDK 17 и Android SDK (build-tools 34, platform 34)
```
Скрипт делает всё сам: aapt2 → javac → d8 → zipalign → apksigner
(Gradle не используется).

## Подпись и обновления
Ключ лежит в `release.keystore` (пароль хранилища и ключа: `lasttower`).
**Не теряйте keystore**: обновления APK должны подписываться тем же ключом,
иначе Android откажется ставить поверх, а сейвы игрока привязаны к приложению.

## Что внутри обёртки
- иммерсивный полный экран (системные панели скрыты);
- экран не гаснет во время игры (`FLAG_KEEP_SCREEN_ON`);
- кнопка «назад» = двойное нажатие (защита от случайного выхода из забега);
- автопауза игры при сворачивании (WebView onPause + visibilitychange в игре);
- иконка в неоновом стиле игры (`res/drawable/ic_launcher.png`).
